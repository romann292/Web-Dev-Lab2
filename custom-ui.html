📖 Complete Catalog of CSS Concepts Studied & Demonstrated

01 CSS Grid & Flexbox Alignment Models Layout
Utilizes CSS Grid with grid-template-columns: repeat(auto-fit, minmax(...)) for dynamic responsive layouts, paired with Flexbox cross-axis and main-axis alignment for pixel-perfect card component nesting.
02 3D Transforms, Depth & Perspective 3D Engine
Employs perspective: 1000px, transform-style: preserve-3d, rotateY(180deg), and backface-visibility: hidden to produce real 3D spatial flipping cards and rotating isometric polyhedra.
03 Conic-Gradients & Laser Orbiting Keyframes Special Effects
Demonstrates animated rotating borders using continuous conic-gradient sweeps behind masked frosted glass cards, producing dynamic cybernetic glowing rims.
04 Glassmorphism & Backdrop Filters Aesthetics
Uses high-fidelity frosted glass rendering with backdrop-filter: blur(25px), multi-layered RGBA alpha channels, inner rim borders, and diffuse multi-stage box-shadows.
05 CSS Custom Properties & Real-Time Theme Engine State & Tokens
Architecture built around CSS variables (--primary-accent, --bg-glass, --glow-color) enabling instant zero-reflash runtime theming across Cyberpunk, Rose Dream, Frost Crystal, and Matrix palettes.
